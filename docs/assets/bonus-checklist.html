Bonus #3 - Checklist

Publicar no GitHub Pages

Passo a passo para colocar sua pagina no ar pela pasta docs

Use este checklist depois que o arquivo `index.html` estiver pronto no seu computador.

1 Preparar os arquivos 5 min
Crie uma pasta do projeto
Use um nome simples, sem espacos e sem acentos. Exemplo: minha-pagina.
Crie a pasta docs
Dentro do projeto, crie uma pasta chamada docs. O GitHub Pages vai publicar a partir dela.
Coloque o index.html dentro de docs
O caminho final deve ficar assim: docs/index.html.
Coloque imagens em docs/assets
Se sua pagina tiver imagens, crie docs/assets e use caminhos relativos.
Teste no navegador
Abra o arquivo docs/index.html no navegador e confira se texto, botoes e imagens aparecem.
Dica: se a imagem nao aparece, confira se o nome do arquivo esta igual no codigo e na pasta. Maiusculas e minusculas importam.
2 Criar o repositorio no GitHub 5 min
Entre no GitHub
Acesse github.com e faça login na sua conta.
Clique em New repository
Crie um novo repositorio para a pagina.
Escolha um nome simples
Exemplo: minha-pagina, meu-curso ou link-da-bio.
Deixe como Public
O GitHub Pages gratuito funciona melhor com repositorio publico.
Crie o repositorio
Clique em Create repository.
3 Enviar a pasta docs 10 min
Clique em uploading an existing file
Na tela do repositorio vazio, use a opcao de enviar arquivos existentes.
Arraste a pasta docs
Envie a pasta docs inteira, com o index.html dentro.
Confira os arquivos antes de salvar
O GitHub deve mostrar algo como docs/index.html.
Escreva uma mensagem simples
Exemplo: Adicionar pagina inicial.
Clique em Commit changes
Isso salva os arquivos no repositorio.
Atenção: se você enviar apenas o arquivo, sem a pasta docs, a configuração abaixo não vai encontrar sua página.
4 Configurar o GitHub Pages 5 min
Abra Settings
No repositorio, clique em Settings.
Entre em Pages
No menu lateral, clique em Pages.
Escolha Deploy from a branch
Em Build and deployment, selecione Deploy from a branch.
Selecione a branch main
Em branch, escolha main.
Selecione a pasta docs
No campo da pasta, escolha /docs, nao /root.
Clique em Save
Aguarde alguns minutos para o GitHub publicar.
Link esperado: https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/
5 Testar a pagina publicada 5 min
Abra o link do GitHub Pages
Depois da publicação, abra a URL gerada pelo GitHub.
Confira se não aparece /docs/ no link
O correto e abrir sem /docs/. Se precisar de /docs/, volte em Settings > Pages e escolha a pasta certa.
Teste no celular
Abra a pagina no celular e confira se os botoes cabem na tela.
Clique em todos os botoes
WhatsApp, checkout, formulario, aula gratuita e links externos devem abrir corretamente.
Corrija e envie de novo se precisar
Se alterar o arquivo, envie a nova versão para o GitHub e aguarde o Pages atualizar.
Pronto: sua pagina esta publicada no GitHub Pages e pode ser compartilhada.

Resumo rapido

Crie docs/index.html → envie para o GitHub → Settings → Pages → main + /docs → Save → teste o link publicado.
