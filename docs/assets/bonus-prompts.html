📌 Como Usar Este Material

Cada prompt foi projetado para ser copiado e colado direto na IA (ChatGPT, Claude, Gemini, Grok, etc.). Siga este fluxo:

  • 1. Escolha o prompt do nicho e tipo de página que deseja.
  • 2. Substitua os campos entre colchetes: [Nome], [Cor Principal], [Link], etc.
  • 3. Envie para a IA com a instrução final: "Gere o código completo em um único arquivo HTML. Não use frameworks. Entregue pronto para copiar e colar."
  • 4. Salve como index.html e suba em Netlify, Vercel ou GitHub Pages (ensinado no curso).
  • 5. Teste no celular. Se precisar de ajustes, peça à IA: "Ajuste o espaçamento e deixe os botões mais visíveis em telas pequenas."

💡 Dica de ouro: Nunca peça "algo bonito" sem contexto. A IA responde melhor a estrutura + cores + comportamento + limitação técnica.

⚙️ Bônus: 10 Prompts de Otimização & Integração

Use estes prompts após gerar a página base. Eles adicionam funcionalidades profissionais sem complicação.

O1Integração
Formulário → E-mail Automático
Adicione ao formulário HTML existente o atributo action="https://formspree.io/f/[SEU_ID]" e method="POST". Inclua mensagem de sucesso e redirecionamento para página de obrigado. Não use backend.
O2Performance
Otimização para Carregamento Rápido
Minimize o CSS e JS inline. Remova fontes externas e use system-ui. Comprima imagens com placeholder base64 se necessário. Mantenha o arquivo único abaixo de 50KB.
O3SEO Básico
Meta Tags & Acessibilidade
Adicione ``, `<meta name="description">`, `<meta name="viewport">`, e `alt` em todas as imagens.
